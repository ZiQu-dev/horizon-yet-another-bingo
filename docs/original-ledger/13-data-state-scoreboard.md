### Parity risks
1. The sidebar is one shared sidebar for everyone (sc-02, sc-17, sc-21): no per-team Team line, no own-row marker, rows all white, and players with no team see the in-game sidebar too (sc-26). Most visible difference on any multi-team game.
2. Scoreboard Auto Hide is not wired (sc-28): sidebar shows when the original hides it.
3. Bossbar text differs (bb-02): "MM:SS left" in English literal instead of "Time Remaining: <time> or <goal>" (translation rule in CLAUDE.md is also broken by this literal). The goal is not shown. No bar when there is no time limit (bb-05), and the lobby bar is missing (bb-09).
4. Bossbar progress and sidebar time come from ticks, not wall clock; server offline time is not subtracted (sc-16, bb-04). Visible on lag or restart.
5. Ranking: own-team row not kept in top 8 (sc-08); showCompleted* and showLeadingTeam options fixed on (sc-20); multi-team Goal "+N" ignores team's own wins (sc-12).
6. Stalemate win message missing (sc-25).
7. Data: no reload, no pack or datapack reading, no /bingodata command (dt-01 to dt-13). The unobtainable tag is static, so changes to loot tables do not change it (dt-06). Team presets are static (dt-07).
8. Lobby objectives bingo_items / bingo_lines / bingo_cards missing (sc-33): visible only through /scoreboard.
9. Persistence is a plain JSON game-state.json written only while Playing (st-10): a lobby or postgame state is not saved, unlike the original's gzip BingoState snapshot.
