### Parity risks
1. Title BINGO! button (17-client-rest-12, -14): always shown in the port, even with the option off; and the click shows the hint text instead of the vanilla Create World screen. Most visible on the title screen.
2. Game end sounds (17-client-rest-05): the original plays win/lose from the game-over packet as well as from card_completed, so the winner or loser hears it at the end. The port plays only the card_completed one.
3. Config screen reach (17-client-rest-22): the original has a Mod Menu entry and four YACL categories. The port has no visible entry; the screen opens only from an unbound key.
4. Player toggles and message toggles outside the settings screen (17-client-rest-18, -20): leading, score and item messages and bossbar, scoreboard, night vision are only set by /bingo prefs or the info book.
5. Missing Stats tab and stats sync (17-client-rest-21, -28): no Sync stats toggle; no stats exchange between clients.
6. Unstarted bingo world not deleted on exit (17-client-rest-40): leftover saves in the world list.
7. Resource packs missing (17-client-rest-30): the Resource Packs screen lacks bingo:classic and bingo:futurist.
8. Sound group descriptions and hover text (17-client-rest-10): the port omits them.
9. Local settings file copy (17-client-rest-26) and the config-changed refresh (17-client-rest-24) are not verified.
