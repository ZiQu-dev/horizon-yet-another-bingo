4. Hide on F3 never triggers (lib.rs:347), though the option defaults ON in config-menu.png.
5. Card Scale label: config-menu.png shows "1.0", config-menu-3.png shows "100%". Port formats as percent; decide which the target uses.
6. Show Multiple Cards default differs between screenshots (OFF in config-menu.png, ON in config-menu-3.png). Check config.rs default against the original.
7. Clicking a tile to open a recipe (JEI/REI/EMI) is missing. Visible when a player clicks a card tile.
8. Entity tooltips (tooltip_v2 over entities) not drawn.
9. Pause when viewing card: default ON in the shot, not traced in port.
10. Stale DESIGN.md: section 9 says the settings screen is not ported and screen_placement.rs is unused; settings_screen.rs now exists. Re-check before trusting section 9.
