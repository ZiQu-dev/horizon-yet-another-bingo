### Parity risks
1. Countdown first second: the original shows the number "3" at once, the port shows BINGO / Game is starting! for the first second (14-04). Most visible in every game.
2. Countdown body: players stay visible and can jump, and use block, entity and item during the countdown; the original hides them, rides them on bats and cancels use/attack (14-11, 14-13). Also no tick freeze found (14-14).
3. Countdown timing: no 5-second lobby delay (14-01), countdownSeconds config not read (14-02), wall-clock steps (14-03), and countdown titles go to spectators in the port (14-09).
4. Lobby admin flow missing: `/bingo lobby` warnings, confirm, restart, edit/save/cancel (14-24..14-29), and the join hints (dialog or chat) for dedicated servers and singleplayer operators (14-21, 14-22). Any player on a dedicated server or singleplayer operator sees these first.
5. `/coords` and `/coords list` missing, while the hint page advertises `/coords` to everyone (14-42, 14-49, 14-50).
6. Tutorial book: given once per session, not re-given after loss, no lobby-mode check, `/bingo book` gated the wrong way round (14-34, 14-35), no duplicate culling (14-44), operator welcome line for non-lobby mode missing (14-40), keep and death drops missing (14-37, 14-53).
7. Death drops and tab list: vanish/keep drops and the green ready check in the tab list (14-53, 14-54).
8. Lobby chaos prevention, spectator advancements block, team spawnpoint forcing (14-55, 14-58, 14-59) are not in the port; affects lobby play, not the countdown.
9. Team chat is a round option (`teamChat`), not the config; spectator chat isolation cannot be turned off (14-45). Team chat bracket colour not verified (14-46).
10. Countdown sounds: no vanilla pling fallback for non-mod clients; the port uses its own sound keys (14-08).
11. Reset from any state in port; original only from PLAYING or POSTGAME in lobby mode (14-30).
12. Placeholders (`%bingo:time%`), voice chat groups, public API, message files: not ported (14-61, 14-62, 14-63, 14-64). Decide scope with the maintainer.
