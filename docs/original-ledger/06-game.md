### Constants and data worth copying exactly
- Chat rule: 40 x `┄` (U+2504), colour yellow, top and bottom (game_end.json, xref). Port uses the same glyph count (texts.rs:403-405) but no colour.
- End reason text colour: YELLOW when it is the message (GameOverService.kt:126); no colour for plain title.
- Time line: `  Game duration: ` + time in GREEN (GameOverController.kt:71-75; en_us.json:124).
- Seed line: `  Seed: <seed>`, seed bracketed and copyable (GameOverController.kt:76-79; en_us.json:136).
- Score row: gray `N. ` (index + 1), team name, ` - `, score, ` - `, duration via `formatString()` or `DNF` (GameOverController.kt:50-61).
- Dialog colours (not used by port, record only): duration value `0xFF_CCA3F5` (purple), separator ` — ` gray (GameOverService.kt:306-315).
- Keys and English (en_us.json, xref): reasons 126-131 (BINGO!, Lockout!, Stalemate!, Soft-locked!, Out of time!, Stopped by %s, Game over!); messages 121-125,137-141; stats.game_duration "Game Duration"; world.keep_playing "Keep Playing"; world.return_to_lobby "Return to Lobby"; world.extend_time_limit_by "Extend time by %s"; world.extend_goal_to "Extend goal to %s"; world.extend_game_to "Extend to '%s'"; world.extend_game_to_infinite "Extend to Infinite Mode"; gui.close "Close"; command.end.success "Stopped the game!"; command.resume.success "Resumed the game!".
- Time limit extension: 15 min (BingoConfig.kt:61-62, `extendRoundTimeLimitByMinutes = 15`); "near limit" = under 30 s remaining (GameResumeService.kt:68).
- Resume goal steps: normal Lines +2, Items +8 (max `BingoGoal.MAX_ITEMS`); ReplaceGoals Lines +5, Items +25 (GameResumeService.kt:101-115).
- `/bingo resume` is offered only when `isLobbyMode` (GameResumeService.kt:41-51).
- Timings (server ticks, 20/s): POSTGAME, chat, packets, and the end-screen open happen in the tick of `end`; status packet repeats 1 s later (GameStatusController.kt:47); game-over packet repeats every tick while over (GameOverController.kt:150-156); time-limit end fires when the timer reaches the limit.

### Parity risks (most visible first)
1. No game-over sound (game-21). Winners hear the card sound only, and nobody hears anything when time runs out or the game is stopped. The original plays GAME_WON or GAME_LOST when the end screen arrives; a winner whose completion ends the game hears GAME_WON twice.
2. Chat end block differs (game-05, game-06, game-07): no seed line, no colours or two-space indent, no blank line before the ranking, no "had the most X" / draw / "won by stalemate" line, and the port adds lines the original never sends ("The game has ended." and "X won the game!" are not in en_us.json). Spectators get it in lobby mode in the original.
3. End screen opens on the Cards tab always (game-13). The original opens Scores when several teams finished or it is a draw.
4. Ranking rows never show DNF (game-10); unfinished teams look finished.
5. Stop command reason loses the name (game-04): original `Stopped by <name>`.
6. The end screen has no primary Return to Lobby / Keep Playing button (game-37, game-38) and never shows the resume description; wire leaves is_ready_vote_available false.
7. Resume changes are much smaller in the port (game-30..36): no goal increase, no AllWin / Infinite switch, no time-limit rule under 30 s, no stalemate reset, no restore of players' positions and inventories (lobby mode).
8. The end-screen state is not re-sent on each tick or on rejoin (game-16, game-27), so a relogging player loses the end screen.
9. Memento map item text and lore differ (game-43): original has "Trophy of the Bingo Victor" / "Relic of a Lost Bingo" and team-name, reason, message, duration, and start time lore.
10. Start warnings are not sent to every CONFIGURE_GAME player and the 2 s title cooldown is missing (game-47, game-48).
11. Ranking order (game-11) is UNSURE: port sorts by lines then items; compare with ScoreRankingService.kt.
