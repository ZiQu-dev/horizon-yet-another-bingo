### Parity risks
1. Card look: only the default sprites exist in the port; the *_shadowed GUI card textures and the classic/futurist packs (opaque cards, different text colours) do not (resources-01, resources-10, resources-11).
2. Simplified squares are absent: 40 one_of squares (Any Banner, Any Bed, Any Wool, Any Flower...) never appear on a Simplified card (resources-26).
3. Challenge count squares are absent: 33 items with random counts (many_*) and 6 NBT squares never appear (resources-25).
4. Stat squares ignore min and max: never_sleep_in_bed inverts (sleeping completes it in the port); random minimums not rolled (resources-27).
5. Head pictures missing: 7 objectives show an item, not a head (resources-14).
6. Waxed frame missing: waxed copper objectives have no frame (resources-07, resources-34).
7. No starting kit by default; no team chest (resources-31, resources-32). Players start with empty inventories.
8. Filter presets missing: only the default filter; no Overworld, Nether or End pools (resources-29, resources-30).
9. Spawn avoidance missing: teams can spawn on powder snow, cactus, magma, oceans, beaches (resources-35).
10. Tooltip frame missing (resources-05).
11. Lang: en_us is a superset (port-only keys); 12 translations with placeholder anomalies may print raw or misplaced arguments (resources-18).
12. Item pictures exist only in the player's built jar; without them the card has no icons (resources-13).
13. Spawn POI (0,17,1, yaw -180) unused (resources-20).
14. Read method: lang files compared by key set and placeholders, not by line; PNGs checked by size and mode only, not viewed; OGG checked by size only, not decoded; objectives and tags checked by structure and counts, not per-field in the port.
