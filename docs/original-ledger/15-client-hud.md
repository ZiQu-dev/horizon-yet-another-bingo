### Parity risks
Ordered by how visible they are to a player.
1. Score messages do not fade: the host's ReadOnly::draw_text forces alpha 0xFF (bingo-native/src/lib.rs:448-455), so every message pops in and out (15-client-hud-39).
2. Ready title does not pulse: same cause, title always solid white (15-client-hud-49).
3. Win fireworks: stars are upright, unscaled and opaque, then vanish at the threshold (lib.rs:439 PORT-GAP, host.rs:31-44, lib.rs:448-455) (15-client-hud-35).
4. Chat-open HUD interaction is absent: clicking the card does not open it (latch never set, 15-client-hud-58), no hover outline (59), no tile tooltip (60), no team player-list tooltip (61).
5. Entity player tooltip never shows: looked_at_player is never answered (lib.rs:275-276) (15-client-hud-63).
6. Card key with no cards is silent; the original shows a hotbar line (15-client-hud-56).
7. showMultipleCards: other cards never drawn (15-client-hud-30).
8. hideOnF3 never fires: debug_screen is always false (lib.rs:347, 521), so with F3 open the card, ready line and tooltip stay (15-client-hud-27, 28, 53).
9. Message size ignores the chat text size: chat_scale is fixed at 1.0 (client.rs:draw_hud) (15-client-hud-43).
10. Stack counts missing on message icons and on 12 and 9 px stacks (15-client-hud-15, 47); durability bars never drawn (16).
11. Sneak-ready uses V2 only (15-client-hud-54).
12. Team outlines show when the original hides them with showMultipleCards on (15-client-hud-22).
13. Fireworks centre scales with cardScale and the range is not truncated; the original uses unscaled 61/66 and toInt (15-client-hud-32, 33).
14. Dark outline: port uses integer floor, original uses float then toInt; can differ by one level (15-client-hud-23).
15. Unverified: custom decoration texture name (19), team colour fallback order (04), game-over screen open-once rule (65).
